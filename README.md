* Config user.name và user.email trong git:
//
git config --global user.name <tên github>
git config --global user.email <email github>
\\

!! Các bạn gửi tên github cho nhóm trưởng để add vào collaborators.

* Cách lấy folder:
//
git clone https://github.com/anhnguyenms2510421-design/HPMR-NNLT
\\
* tạo branch:
//
git branch
git switch -c <tên branch>
git branch                       #kiểm tra lại xem đã vào đúng branch chưa
\\
* Chỉnh sửa:
//
code .
\\
* Sau khi chỉnh sửa, commit và push:
//
git status
git add .
git status
git commit -m "<tên commit>"
git push origin <tên branch>
\\
* Pull code từ main:
//
git p//ull origin main
\\
